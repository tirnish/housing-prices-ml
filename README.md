

## Загрузка данных

Для загрузки исходных данных используется `src/download_data.py`.

Перед запуском скрипта необходимо настроить доступ к Kaggle API.

```python
import kagglehub; kagglehub.login() 
```

Проверить авторизацию можно командой:

```bash
python -c "import kagglehub; print(kagglehub.whoami())"
```

После успешной авторизации запустите:

```bash
python src/download_data.py
```

Скрипт загружает данные соревнования Titanic и сохраняет их в директории:

```text
data/raw/
├── train.csv
└── test.csv
```

## Цель проекта
Цель проекта: предсказать цену продажи для каждого дома. Для каждого Id в тестовом наборе необходимо предсказать значение переменной SalePrice. 

Проект демонстрирует методику взимодействия с объемным датасетом, содержащего большое количество признаков.

**Метрика**: RMSE
